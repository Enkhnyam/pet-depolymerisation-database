## The checks, and what each one reads

- **`checks/curated/answer_key.py`** — *The curated answer key: how big it is, what it leaves blank, and whether it holds together.*  
  reads: answer_key = CURATED
- **`checks/curated/extractions.py`** — *Every benchmark extraction scored against the curated answer key.*  
  reads: answer_key = CURATED; extractions = RUNS_DIR / 'extract_*'
- **`checks/curated/field_types.py`** — *Why the two graders agree as much as they do.*  
  reads: answer_key = CURATED; extraction = EXTRACTION; judge = JUDGE
- **`checks/curated/gao_overlap.py`** — *Our automatic extraction against Gao et al.'s hand-curated ionic-liquid glycolysis set.*  
  reads: gao = GAO; crosswalk = PAPERS
- **`checks/curated/judged_runs.py`** — *What each judge said about each extraction, on the curated papers.*  
  reads: answer_key = CURATED; extractions = RUNS_DIR / 'extract_*'; judges = RUNS_DIR / 'judge_*_on_*'
- **`checks/curated/matrix.py`** — *The judge x extraction agreement matrix -- the paper's headline table.*  
  reads: answer_key = CURATED; extractions = RUNS_DIR / 'extract_*'; judges = RUNS_DIR / 'judge_*_on_*'
- **`checks/curated/metric.py`** — *Is the metric grader behaving, and where does it lose records?*  
  reads: answer_key = CURATED; extraction = EXTRACTION
